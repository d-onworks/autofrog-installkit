## 시험 중 찾아서 고친 것
1. 코덱스 설정 파일이 처음부터 없으면 `config.toml` 이 안 만들어지고 임시 파일만 남던 문제 → 고침, 쓰기 확인까지 추가
2. `cc`(클로드 바로 실행)를 파일로 만들면 맥의 C 컴파일러 `cc` 와 이름이 겹침(터미널에선 컴파일러가 잡히고, 순서가 바뀌면 npm 컴파일이 클로드를 부름) → 셸 별칭으로 변경
3. 이미 있는 Node 의 npm 전역 폴더를 쓸 수 있는데도 바꾸던 조건 → 진짜 못 쓸 때만 바꾸게
4. 버전 표의 한글 이름 줄 맞춤 어긋남

## 확인한 화면 (사람이 누르는 창)
- "'xcode-select' 명령어는 명령어 라인 개발자 도구가 필요합니다 [취소] [설치]" — 키트가 띄우고 기다리는 창. 가상머신에 클릭을 보낼 수 없어 **누른 뒤의 흐름은 미검증**(관리자 암호 확인된 상태의 무창 설치로 대신 검증)
- "'터미널'이(가) 다운로드 폴더의 파일에 접근하려고 합니다 [허용 안 함] [허용]" — 다운로드 폴더에서 실행하면 뜸. 누를 때까지 설치가 멈춰 있음 → 안내문·매뉴얼에 추가
- "'1-install.command'을(를) 열지 않음 [휴지통으로 이동] [완료]"
