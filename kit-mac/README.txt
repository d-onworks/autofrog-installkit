오토프로그 바이브코딩 설치 키트 (맥 · macOS 13.5 이상, 애플 실리콘·인텔 모두)

※ 설치하면서 공식 배포처에서 프로그램을 내려받습니다. 인터넷이 연결된 상태에서 실행하세요.
  끝나면 VS Code 가 저절로 열립니다.

1. 받은 zip 파일을 더블클릭 → 같은 자리에 폴더가 생깁니다(zip 안에서 바로 실행하지 마세요)
2. 풀린 폴더의 [1-install.command] 더블클릭 → 5~15분 기다리기
   - "1-install.command을(를) 열지 않음" 창이 뜨면 [완료] → 시스템 설정 → 개인정보 보호 및 보안
     → 아래쪽 [그래도 열기] → 맥 암호 입력
   - 그래도 안 열리면: 터미널 앱을 열고  bash  (한 칸 띄우고) 를 친 뒤,
     1-install.command 파일을 터미널 창에 끌어다 놓고 Enter
   - "터미널이 다운로드 폴더의 파일에 접근하려고 합니다" → [허용]
   - "명령어 라인 개발자 도구" 설치 창이 뜨면 [설치] → [동의] (Git 이 들어 있습니다)
   - VS Code 가 켜져 있으면 저장하고 닫으라고 물어봅니다
   - 끝나면 버전 표가 나오고, 전부 [ OK ] 면 성공
3. [2-login.command] 더블클릭 → 코덱스·클로드·GitHub·Vercel·Supabase 순서로 브라우저 로그인

설치되는 것: Git(애플 개발자 도구), Node.js 24, GitHub CLI, Supabase CLI, VS Code(+한국어·코덱스·클로드 확장),
            Vercel CLI, 클로드 코드, 코덱스
바로가기 명령: cx = 코덱스를 확인 없이 바로 실행, cc = 클로드를 확인 없이 바로 실행
              (확인 없이 실행은 파일을 마음대로 고칩니다. 연습 폴더에서만 쓰세요)

관리자 권한 없이 내 계정 폴더에만 설치합니다(애플 개발자 도구만 맥이 직접 설치).
기록 파일: 홈 폴더/autofrog-kit-logs — 막히면 이 폴더를 통째로 강사에게 보내 주세요.
