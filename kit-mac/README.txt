오토프로그 바이브코딩 설치 키트 (맥 · macOS 13.5 이상, 애플 실리콘·인텔 모두)

이 폴더는 한 줄 설치가 내려받아 쓰는 스크립트입니다. 직접 실행할 파일은 없습니다.

설치: ⌘+Space → "터미널" → 아래 한 줄을 붙여 넣고 Enter (안내: https://autofrog.kr/kit)
  curl -fsSL https://autofrog.kr/kit.sh | bash

- "명령어 라인 개발자 도구" 설치 창이 뜨면 [설치] → [동의] (Git 이 들어 있습니다)
- 5~15분 뒤 버전 표가 전부 [ OK ] 면 성공. 이어서 로그인할지 묻습니다.
- 나중에 로그인: 새 터미널 창에서  autofrog-login
- 바로가기 명령: cx = 코덱스, cc = 클로드를 확인 없이 바로 실행(연습 폴더에서만)

관리자 권한 없이 내 계정 폴더에만 설치합니다(애플 개발자 도구만 맥이 직접 설치).
기록 파일: 홈 폴더/autofrog-kit-logs
