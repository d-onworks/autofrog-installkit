설치 명령 한 줄 복사 — 1번이 안 되면 2번

autofrog.kr/kit 에 들어가 [복사]를 누릅니다. (라운지 설치 카드의 [복사]도 같습니다)

1번powershell -ExecutionPolicy Bypass -c "irm https://autofrog.kr/kit.ps1 | iex"

백신이 1번을 "트로이 목마"로 잡거나 "액세스가 거부되었습니다"로 끝나면 2번. 설치되는 것은 같습니다.

2번powershell -NoProfile -c "irm https://autofrog.kr/kit.ps1 -OutFile $env:TEMP\af.ps1; powershell -NoProfile -ExecutionPolicy Bypass -File $env:TEMP\af.ps1"

Win + R → 붙여넣기 → Enter → 기다리기

  • 파란 PowerShell 창이 뜨고 설치가 시작됩니다. 창을 닫지 말고 기다리세요.
  • VS Code가 켜져 있으면 저장하고 닫으라고 묻습니다. Enter 를 누르면 닫고 이어서 설치합니다.
  • 아래 8가지가 순서대로 깔립니다. 모두 공식 배포처에서 받아 파일 지문(체크섬)·서명을 확인합니다.

끝나면 버전 표가 나오고 VS Code가 저절로 열립니다. 10줄 모두 [ OK ]면 성공. [실패] 줄은 캡처해 클로드 대화창에 붙여 넣으세요. 같은 한 줄을 다시 실행하면 실패한 것만 다시 합니다.

"이어서 로그인할까요?" → Enter

아래 순서로 하나씩 물어봅니다. 브라우저가 열리면 로그인·승인하고 창으로 돌아오세요. 지금 못 하면 나중에 바탕화면 [오토프로그 로그인] 아이콘을 두 번 누르면 남은 것만 다시 묻습니다.

코덱스 · 클로드ChatGPT / 클로드 계정으로 로그인. 클로드는 로그인이 끝나면 /exit 를 입력해 나옵니다.
GitHub화면의 8자리 코드가 자동 복사됩니다 → Enter → 열린 브라우저에 붙여 넣고(Ctrl+V) 승인.
Vercel브라우저가 열리면 Continue with GitHub.
Supabase브라우저의 확인 코드(8자리)를 복사해 붙여 넣고 Enter. 붙여 넣어도 화면에 안 보이는 게 정상입니다.
에러가 나면 에러 화면을 캡처해(Win+Shift+S) 클로드 대화창에 붙여 넣고 "이거 해결해 줘" → 알려 주는 대로 따라 하면 대부분 해결됩니다.
둘 다 막히면 autofrog.kr/kit.zip 을 받아 압축 풀기 → 1-install.bat 두 번 클릭. "스마트 앱 컨트롤이 차단했습니다" 창이 뜨면 클로드나 코덱스 앱에 "스마트 앱 컨트롤 꺼 줘"라고 하세요(한 번 끄면 윈도우를 새로 깔기 전엔 다시 못 켭니다). 회사 클로드 팀 계정은 팀 관리자가 내 계정을 승인해야 로그인됩니다.
