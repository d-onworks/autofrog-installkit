PowerShell 창 열고 한 줄 붙여넣기

Win 키 → powershell 입력 → 그냥 Enter (관리자로 실행 아님 — 일반 계정 PC 는 관리자 계정 쪽에 깔려 내 계정에서 안 보입니다)

autofrog.kr/kit 의 [복사] → 열린 창에 붙여넣기(Ctrl+V) → Enter

irm https://autofrog.kr/kit.ps1 | iex

Win + R 로 하려면 실행 창에 아래 줄. 오류가 나도 창이 닫히지 않습니다.

Win+Rpowershell -NoProfile -ExecutionPolicy Bypass -NoExit -c "irm https://autofrog.kr/kit.ps1 -OutFile $env:TEMP\af.ps1; & $env:TEMP\af.ps1"

기다리기 — 창을 닫지 마세요

  • 파란 PowerShell 창이 뜨고 설치가 시작됩니다. 창을 닫지 말고 기다리세요.
  • VS Code가 켜져 있으면 저장하고 닫으라고 묻습니다. Enter 를 누르면 닫고 이어서 설치합니다.
  • "스마트 앱 컨트롤을 끌까요?" → Enter → 관리자 확인 창 [예] (켜져 있으면 Git 이 막힙니다)
  • 아래 8가지가 순서대로 깔립니다. 모두 공식 배포처에서 받아 파일 지문(체크섬)·서명을 확인합니다.
GitNode.js 24GitHub CLISupabase CLI VS Code +한국어Vercel CLI클로드 코드코덱스
끝나면 버전 표가 나오고 VS Code가 저절로 열립니다. 10줄 모두 [ OK ]면 성공. [실패] 줄은 캡처해 클로드 대화창에 붙여 넣으세요. 같은 한 줄을 다시 실행하면 실패한 것만 다시 합니다.

"이어서 로그인할까요?" → Enter

하나씩 물어봅니다. 브라우저에서 로그인·승인하고 돌아오세요. 나중에 하려면 바탕화면 [오토프로그 로그인] 아이콘.

코덱스 · 클로드ChatGPT / 클로드 계정으로 로그인. 클로드는 로그인이 끝나면 /exit 를 입력해 나옵니다.
GitHub화면의 8자리 코드가 자동 복사됩니다 → Enter → 열린 브라우저에 붙여 넣고(Ctrl+V) 승인.
Vercel브라우저가 열리면 Continue with GitHub.
Supabase브라우저의 확인 코드(8자리)를 복사해 붙여 넣고 Enter. 붙여 넣어도 화면에 안 보이는 게 정상입니다.
에러가 나면 에러 화면을 캡처해(Win+Shift+S) 클로드 대화창에 붙여 넣고 "이거 해결해 줘" → 알려 주는 대로 따라 하면 대부분 해결됩니다.
그래도 막히면 autofrog.kr/kit.zip 을 받아 압축 풀기 → 1-install.bat 두 번 클릭. "스마트 앱 컨트롤이 차단했습니다" 창이 뜨면 클로드나 코덱스 앱에 "스마트 앱 컨트롤 꺼 줘"라고 하세요. 회사 클로드 팀 계정은 팀 관리자가 내 계정을 승인해야 로그인됩니다.

시작하기
