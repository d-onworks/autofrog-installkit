원클릭 설치 프로그램 매뉴얼 맥

macOS 13.5 이상 · M1~ / 인텔
설치 약 10~25분 · 로그인 약 10분

①설치는 파일 하나만 누르면 수업 프로그램이 한 번에 깔리고 claude·codex 명령이 바로 실행됩니다. ②로그인만 터미널에서 한 줄씩 직접 합니다.

0

받아서 압축 풀기

라운지 → 수업자료 1주 → 원클릭 설치 프로그램(맥 zip) 내려받기 → zip을 더블클릭하면 같은 자리에 autofrog-setup-kit-mac 폴더가 생깁니다.

1

1-install.command 더블클릭 → 기다리기

  • "1-install.command을(를) 열지 않음" → 완료 → 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 그래도 열기 → 맥 암호.
  • 터미널이 다운로드 폴더에 접근하려고 합니다 → 허용.
  • 명령어 라인 개발자 도구가 필요합니다 → 설치 → 동의. 끝나면 터미널이 저절로 이어 갑니다(Git이 여기 들어 있음).
  • VS Code가 켜져 있으면 저장 후 Enter → 닫고 이어서 설치합니다.
Git 개발자 도구Node.js 24GitHub CLISupabase CLI VS Code +한국어Vercel CLI클로드 코드코덱스
끝나면 버전 표가 나오고 VS Code가 저절로 열립니다. 10줄 모두 [ OK ]면 성공. 여러 번 눌러도 괜찮습니다.
2

터미널 창에서 한 줄씩 로그인

⌘+Space → 터미널을 새로 열고 아래 명령을 한 번씩 입력합니다. 브라우저가 열리면 승인하고 돌아오세요.

claude클로드가 바로 실행되는지 확인 → 로그인 화면이 나오면 안내대로. 끝나면 /exit. (코덱스를 쓰면 codex)
gh auth login묻는 말은 Enter 만 계속 누르면 됩니다 → 화면의 8자리 코드를 열린 브라우저에 입력하고 승인.
vercel login브라우저가 열리면 Continue with GitHub.
supabase login브라우저의 확인 코드를 복사해 붙여 넣고 Enter. 붙여 넣어도 화면에 안 보이는 게 정상입니다.

2-login.command를 더블클릭해도 같은 순서로 물어봅니다.

에러가 나면 ① 화면을 캡처해(⌘+Shift+4) 클로드 대화창에 붙여 넣고 "이거 해결해 줘". ② 1-install.command 가 안 열리면 터미널에 bash 와 빈칸 하나를 치고, 파일을 터미널 창에 끌어다 놓은 뒤 Enter. ③ 회사 클로드 팀 계정은 팀 관리자가 내 계정을 승인해야 로그인됩니다.
3

시작하기

VS Code → 파일 → 폴더 열기로 작업 폴더를 열고 → 터미널 → 새 터미널에서 cx (코덱스) 또는 cc (클로드)를 입력하면 확인 창 없이 바로 시작합니다. 확인 없이 파일을 고치므로 연습 폴더에서 쓰세요.

막히면 홈 폴더의 autofrog-kit-logs 폴더를 통째로 질문 게시판에 올려 주세요.
